# План развития

## 1.0 — выпущено

- Очистка Unity PlayerPrefs, EOS SDK, DevToDev, Sentry, логов и кэша.
- `-WhatIf`, `-Force`, `-Confirm`, `-IncludeShared`.
- Интеграционный тест в песочнице.
- Документация на русском и английском.
- CI на GitHub Actions.

## 1.1 — безопасность и отчётность

- [ ] Параметр `-ReportPath` для сохранения отчёта о запуске в JSON.
- [ ] Сводка «что будет удалено» с размерами файлов.
- [ ] Более точное определение баз DevToDev без ложных срабатываний.
- [ ] Проверка, что игра и лаунчер действительно закрыты.
- [ ] Опциональное создание точки восстановления Windows.
- [ ] Тесты Pester в дополнение к интеграционному тесту.

## 1.2 — удобство

- [ ] Параметр `-Language en` для английского вывода.
- [ ] Конфигурационный файл с дополнительными пользовательскими путями.
- [ ] Режим `-ListTargets` для просмотра списка целей без запуска.
- [ ] Улучшенная справка `Get-Help` с примерами.

## Идеи без версии

- Подпись релизных архивов.
- Автоматическая проверка хешей в документации.
- Расширение тестов на разные версии Windows.

## Вне рамок проекта

- Подмена HWID.
- Обход блокировок, античита и ограничений игры.
- Читы и модификации игрового клиента.
- Поддержка других игр без отдельного исследования и тестов.
- Linux и macOS.

## Как предложить изменение

Создайте issue по шаблону **Feature request** или pull request. Приоритет получают изменения, которые делают очистку безопаснее, понятнее и проверяемее.
