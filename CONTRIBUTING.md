# Как внести вклад в RobCleaner

Спасибо за интерес к проекту! RobCleaner — небольшой инструмент, и любой полезный вклад приветствуется: отчёт об ошибке, улучшение документации, новый тест или аккуратный pull request.

## Перед началом

- Прочитайте [README.md](README.md) и [FAQ.md](FAQ.md).
- Проверьте, нет ли уже похожего issue или pull request.
- Уязвимости **не** обсуждаются в публичных issue — используйте [SECURITY.md](SECURITY.md).
- Проект не принимает функции подмены HWID, обхода блокировок и любые действия, нарушающие правила игры.

## Сообщения об ошибках

Создайте issue по шаблону **Bug report**. Укажите:

- версию PowerShell (`$PSVersionTable.PSVersion`);
- версию Windows;
- режим запуска (`-WhatIf`, обычный, `-Force`, `-IncludeShared`);
- вывод скрипта;
- ожидаемое и фактическое поведение.

Перед публикацией удалите из вывода имя пользователя, пути, токены и другие личные данные.

## Предложения по улучшению

Создайте issue по шаблону **Feature request**. Опишите задачу и причину, а не только готовое решение. Особенно полезны предложения, которые делают очистку безопаснее и понятнее.

## Pull request

1. Сделайте fork репозитория.
2. Создайте ветку с понятным именем: `fix/whatif-output`, `docs/faq`, `test/shared-paths`.
3. Внесите изменения.
4. Запустите тесты (см. ниже).
5. Откройте pull request и заполните шаблон.

Не обязательно делать идеально с первого раза — мы поможем доработать.

## Правила кода

- Целевая версия — **Windows PowerShell 5.1+**. Не используйте синтаксис, доступный только в PowerShell 7, без необходимости.
- Файлы `.ps1` и `.psd1` — **UTF-8 с BOM** и окончания строк **CRLF**. Это важно для корректного отображения кириллицы в Windows PowerShell 5.1.
- Используйте `[CmdletBinding(SupportsShouldProcess = $true)]` и `ShouldProcess` для разрушительных операций.
- Используйте `-LiteralPath` и `Join-Path` при работе с путями.
- Не добавляйте сетевые запросы, скачивание файлов, бинарники и обфускацию.
- Общие пути (`EpicGamesLauncher`, глобальный `Sentry`, `Unity\Analytics`, `UnityGraphicsQuality`) удаляются только при `-IncludeShared`.
- Новый удаляемый путь должен быть:
  - описан в README (RU и EN);
  - покрыт тестом в `tests/Test-RobCleaner.ps1`;
  - безопасен по умолчанию.
- Не добавляйте подмену HWID, обход блокировок и обход античита.
- Комментарии и сообщения для пользователя — на русском; имена функций и переменных — на английском.

## Тесты

Перед pull request выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\Test-RobCleaner.ps1
```

И проверьте, что предпросмотр ничего не удаляет:

```powershell
powershell -ExecutionPolicy Bypass -File .\RobCleaner.ps1 -WhatIf
```

Тест работает в изолированной песочнице и не трогает реальные данные игры. Не добавляйте в тесты реальные пути пользователя.

## Коммиты

Желателен формат [Conventional Commits](https://www.conventionalcommits.org/):

```text
fix: не удалять локальные сохранения с расширением .db
docs: добавить раздел про -IncludeShared
test: проверить сохранение общего ключа Unity
ci: запускать тест на Windows Server 2022
```

## Релизы

1. Обновите версию и дату в `CHANGELOG.md`.
2. Убедитесь, что тест проходит:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tests\Test-RobCleaner.ps1
   ```

3. Создайте аннотированный тег и отправьте его:

   ```powershell
   git tag -a v1.0.0 -m "RobCleaner v1.0.0"
   git push origin v1.0.0
   ```

4. Workflow **Release** запустит тест, соберёт `RobCleaner-v1.0.0.zip`, посчитает SHA-256 и создаст GitHub Release.

Не публикуйте релиз, если тест не проходит или в архив попали реальные данные пользователя.

## Документация

Основной язык документации — русский. Английская версия (`README.en.md`) должна оставаться синхронизированной по смыслу. Если меняете поведение скрипта, обновите:

- `README.md`;
- `README.en.md`;
- `CHANGELOG.md`;
- `FAQ.md`, если вопрос вероятен.
